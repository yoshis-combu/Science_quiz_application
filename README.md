# 理科 記憶クイズ

中学3年生の高校受験に向けた、理科の記憶問題クイズアプリです（中3 第4回ステップ模試の予習プリントのうち記憶・知識を問う設問、全108問）。

- 1セット15問の4択クイズ。出題順はランダムで、周回ごとに全問が必ず1回出題されます
- 正答・誤答の成績を端末（localStorage）に累積し、「強化ポイント」で苦手問題・苦手単元を表示します
- 「苦手を復習」で誤答率の高い問題を集中して解けます

## 使い方
GitHub Pages で公開しています: https://yoshis-combu.github.io/Science_quiz_application/

## 構成
- `docs/index.html` … アプリ本体（外部依存なしの Vanilla JS）
- `docs/questions.js` … 問題データ（問題を追加するときは新しい `id` で追記）
